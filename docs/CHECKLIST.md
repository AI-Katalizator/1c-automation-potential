Обработка собрана без платформы 1С, из исходников, утилитой v8unpack. Автоматически проверены структура файла, совпадение модуля и метаданных после повторной распаковки, синтаксис модуля (BSL Language Server: ошибок разбора нет) и расчёт (Python-зеркало формул на модельных данных даёт все контрольные цифры). Всё, что ниже, можно проверить только в 1С, на тестовой базе.

# 1. Файл открывается

- [ ] Файл → Открыть: нет ошибки «Ошибка формата потока» / «Файл не является внешней обработкой».
- [ ] Предупреждение безопасности появляется и после «Да» форма открывается.
- [ ] Нет ошибок компиляции модуля формы (при открытии и при нажатии кнопок).
- [ ] Заголовок окна «Потенциал автоматизации учёта поступления услуг».

# 2. Форма строится

Форма создаётся программно при открытии (реквизиты, кнопки, поля). Проверить:

- [ ] Видны период, поле «Организация» рядом с периодом, порог N, переключатель «M месяцев из 12», M, «Обезличить поставщиков», кнопки «Сформировать» и «Печать», блок норм (оклад, минуты, коэффициенты).
- [ ] Период по умолчанию — прошлый календарный год.
- [ ] Поле M недоступно, пока режим «M из 12» выключен.
- [ ] Две закладки: «Дашборд» и «Отчёт для печати».

# 2а. Организация (новое в версии 002)

- [ ] Поле «Организация» открывает выбор из справочника организаций; по умолчанию пустое.
- [ ] Пусто: цифры те же, что в версии 001 (все организации), в шапке дашборда и отчёта — «Все организации».
- [ ] Выбрана организация: считаются только её поступления (и справочные цифры «не включены» — тоже только по ней); в шапке — «Организация: <название>».
- [ ] Включено «Обезличить поставщиков»: в шапке дашборда и отчёта, при печати и в PDF — «Организация скрыта», названия нет.
- [ ] Смена организации сбрасывает результат и просит нажать «Сформировать», как смена периода.

# 3. Данные (главное)

На тестовой базе (контрольный пример), период 01.01.2025–31.12.2025, умолчания:

- [ ] Всего 127 документов, 35 поставщиков.
- [ ] Кандидаты 97 от 11 поставщиков, доля 76%.
- [ ] Экономия 6,5 ч и 5 125 ₽ в год, ≈ 427 ₽ в месяц; ставка 792 ₽/ч.
- [ ] Режим «9 месяцев из 12»: 73 кандидата, 3 857 ₽.
- [ ] В отчёте для печати: исключено смешанных поступлений — 3, полученных счетов-фактур — 89.
- [ ] Имена значений перечисления: в коде используются `ВидыОперацийПоступлениеТоваровУслуг.Услуги` (отбор) и `ВидыОперацийПоступлениеТоваровУслуг.ПокупкаКомиссия` (смешанные, только для справочной цифры). Если в релизе имена другие — обработка выведет понятное сообщение; поправить функцию `НастройкиСценарияПоступлениеУслуг()`.
- [ ] Если цифры не сходятся: какие ещё смешанные виды операции есть в релизе (например, отдельный вид для «товары и услуги»), и не попадают ли в «Услуги» документы, которые не должны считаться.
- [ ] Обработка ничего не записывает (нет вопросов о сохранении, журнал регистрации без записей изменения данных).

# 4. Пересчёт без запроса

- [ ] Смена N, M, режима, обезличивания, оклада, минут и коэффициентов сразу меняет цифры на дашборде и в отчёте, без нового «Сформировать».
- [ ] Смена периода или организации сбрасывает результат и просит нажать «Сформировать».

# 5. Дашборд (поле HTML)

- [ ] Дашборд отображается (в тонком клиенте Windows поле HTML может работать на движке Internet Explorer, в веб-клиенте и на Linux/Mac — WebKit). Вёрстка таблицами, без современных CSS-приёмов, но проверить оба варианта, если есть.
- [ ] Кольцо доли (SVG) рисуется. Если в IE-режиме кольца нет — это ограничение движка, цифра доли всё равно видна.
- [ ] Всплывающие подсказки на карточках работают (наведение мышью; запасной вариант — системная подсказка title).
- [ ] Читается на экране 1366×768.
- [ ] Тексты и подписи этапов совпадают с макетом дашборда.

# 6. Печать и PDF

- [ ] Кнопка «Печать» открывает диалог печати.
- [ ] Ширина колонок отчёта задана (если 1С не приняла ширину, колонки будут стандартными — некритично, но выглядит хуже).
- [ ] Файл → Сохранить как… на закладке «Отчёт для печати» сохраняет PDF.
- [ ] Сноска про норму 5 минут есть на дашборде и в отчёте.

# 7. Обезличивание

- [ ] С флагом: на дашборде, в отчёте, при печати и в PDF нет реальных наименований и ИНН поставщиков, только «Поставщик 1…N», и нет названия организации («Организация скрыта»).

# 8. Права и скорость

- [ ] Под пользователем-бухгалтером (без полных прав) отчёт формируется. Если нет — какой роли не хватает.
- [ ] Время формирования за год на тестовой базе (ожидается секунды).
- [ ] Клиент-серверный режим, если есть возможность.

# Для разработчика: допущения в коде

- Форма полностью программная: в файле только пустая форма с реквизитом «Объект», всё остальное создаётся в `ПриСозданииНаСервере`. Так в файле нет описаний элементов, которые нельзя проверить без платформы.
- Формат контейнера 8.3 (версия 216/80315, как у образца из 8.3.15). Поле размера блока оглавления исправлено на 0x200, как пишет платформа.
- В служебном файле `versions` при каждой сборке новые случайные UUID (так же делает и сама 1С). Остальное содержимое от сборки к сборке одинаковое.
